# Student Performance Analyzer

A modular Python package for student score validation,
automated grading, and class performance analytics.

## Project Overview

The performance_analyzer package organizes Python code
into reusable modules. It validates student marks and
calculates grades, GPA, class average, pass percentage,
and the top-performing student.

## Project Structure

student_analyzer_project/
- performance_analyzer/
  - __init__.py
  - validator.py
  - metrics.py
- main.py
- setup.py
- README.md

## Features

1. Validates scores between 0 and 100.
2. Assigns grades and GPA points.
3. Calculates class average and pass percentage.
4. Identifies the top-performing student.
